# 发布检查清单

## 内容

- 标题是否清楚
- 前 3 秒是否有钩子
- 核心记忆点是否明确
- 是否避免教材腔
- 是否有一句适合评论区/标题复用的总结

## 画面

- 黑黄风格是否统一
- 当前关键词是否足够大
- 字幕是否可读
- 画面是否没有文字重叠
- 是否没有长时间卡在同一画面
- 封面是否能一眼看懂主题

## 声音

- 配音是否清晰
- 英文发音是否能听懂
- 字幕是否跟配音同步
- 音频开头和结尾是否没有异常空白

## 文件

- 导出视频命名是否规范
- 封面命名是否规范
- caption 和 publish notes 是否齐全
- 文件是否放在对应 episode 的 `exports/`
- API Key 是否没有出现在任何文件里

## 技术

```powershell
npx tsc --noEmit
npm run render
```

两条命令都应通过。
