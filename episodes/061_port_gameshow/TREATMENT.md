# Treatment: 061_port_gameshow

## 1. Three candidate structures
1. **Five rounds + lightning + report + bonus**: one round per word, then all five at double speed, a grade, a cloze for the comments.
2. **Lightning first as a pre-test**: "先测你一下" fast grid, then the rounds explain, then the grade.
3. **Knock-out**: one wrong option is buzzed out per round until only the answer of the bonus question is left.

**Chosen:** 1, because the first episode of a template must teach its grammar (the round) before it plays with it.

## 2. Logline and arc
- Logline: one pass code, five rounds — beat them all and *port* is yours for life.
- Setup (pass code) → five rising rounds → lightning (proof you learned it) → grade S → the viewer's turn.

## 3. Hook (first 3 seconds)
- First frame: navy sunburst set, 词根闯关 slams with a crash, the pig drops on the floor, five lamps light.
- First line: 词根闯关！一个词根，五关，你能全对吗？

## 5. Signature shot

## 6. Cue map
- Tempo: 120 BPM, key C; scene starts on the half beat.
- Silences: none long; the lightning round is the loudest section, the report hit empties the bar before the stamp.
- Cues come from the line text: prefix, literal, word, first two characters of the meaning.
