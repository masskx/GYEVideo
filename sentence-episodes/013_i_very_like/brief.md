# Episode Brief: 013_i_very_like

## Mode

Chinglish Trap + Kinetic Douyin Visual

## Topic

`我很喜欢不是 I very like`

## Trap Diagnosis

- wrongExpression: `I very like`
- intendedMeaning: `我很喜欢`
- wrongMeaning: `very 只能修饰形容词，不能直接修饰动词 like`
- whyItFails: `中文"很"可以直接放在动词前("很喜欢")，但英语 very 只能接形容词/副词，直接说 I very like 等于语法报警。`
- naturalExpression: `I really like it` / `I love it` / `I like it a lot`
- simpleRule: `very + 形容词 | really + 动词`
- usageScene: `朋友问你喜不喜欢这首歌：I really like this song.`
