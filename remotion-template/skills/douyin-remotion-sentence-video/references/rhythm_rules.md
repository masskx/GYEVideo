# Story Beat Rhythm

Rhythm should come from story progression, not repetition count.

This skill should now match the beat pressure of `douyin-remotion-video`, not merely "have some motion".

## Default Beat Order

Every episode should contain at least these 5 beats:

1. scene cold open
2. wrong expression
3. rescue expression
4. reuse scene
5. ending callback

## Beat Change Rule

Between beats, something visible must change:

- dialogue bubble
- typing state
- strikeout
- message send
- camera push
- rescue line drop
- second scene swap
- flash-word burst
- impact zoom
- compare-board re-balance

Additional lock:

- every 0.5 to 1.2 seconds needs one visible beat
- every 2 seconds needs a clear screen change
- every 2 to 3 beats needs one layout-level change, not just text animation inside the same card
- subtitle changes alone do not count as a visual beat
- when voice keeps moving, the main canvas must also keep evolving

## Forbidden

- the same English line repeated 3 times in a row for no reason
- one static big-text layout for the whole video
- a speed drill that does not advance the scene
- fake energy without dramatic movement
- a final compare scene that simply parks two cards on screen and waits
- long holds where only subtitles move but the main frame does not evolve
- quiet explainer pacing with background music too weak to carry edit energy
- correct phrase reveals that fade in softly instead of landing with payoff motion
- wrong phrase beats that appear neutrally instead of being visually punished

## Optional Drill

`speed-drill` is optional.
Use it only when the episode is genuinely drill-friendly.
Do not force it into emotional rescue scenes.
