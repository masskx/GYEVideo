# Visual Rules

## Motion Over Layout

Default behavior is not to place all information on the screen at once.
Default behavior is to let information happen one beat at a time.

Requirements:

- The sentence skeleton must use a slam reveal.
- A/B slots must use card swap motion.
- English examples must appear one by one.
- Chinese explanation must use short punch-in lines.
- No screen may stay fully static for more than 4 seconds.

## Text Density Rules

- One main screen can hold at most 1 main title, 1 sentence pattern, and 1 helper short line.
- Example scenes should show only 1 main example at a time.
- The cover can have at most 3 information layers.
- English pattern should stay visually dominant.

## Borrowed Motion Language

Sentence videos should reuse the same motion vocabulary as the word skill:

- `slamIn` for major text entrances
- `punchZoom` for impact beats
- `shake` for wrong-expression punishment and payoff hits
- `highlightSweep` for active line emphasis
- `quickCut` for state changes
- `flashOpacity` for interruption flashes

Do not settle for plain fade-in cards when the word skill would use impact motion.

## Frame Fill Rules

- If a card is tall, the content must stack intentionally through the full height.
- If text sits near the top, the lower area must still contain meaningful visual structure.
- Avoid giant empty padding below a single short line.
- A `wrong vs right` ending should feel like a payoff board, not two storage boxes.
- Borders should support the content, not become the main thing the viewer notices.
