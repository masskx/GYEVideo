# Natural Catchphrase

Earworm is not machine repetition.
It is one natural line that stays because the scene makes it stick.

## Requirements

- natural first
- easy to say in one breath
- tied to a real scene
- does not need forced trimming
- does not need 3 repeats to work
- can appear in a real chat bubble

## Repetition Rule

Repeat at most 2 times by default.

Use repetition only when it has a reason:

1. first appearance as the rescue line
2. second appearance as the final callback

Do not force:

- speed drill in every episode
- chorus 3 times by default
- mechanical English chanting

## What The Viewer Should Remember

The viewer should think:

`I know exactly when I can use this sentence.`

Not:

`This video kept shouting one English line at me.`
