# Chinglish Trap Topic Bank

## 1. Classic Chinglish

- Good good study, day day up.
- People mountain people sea.
- Long time no see.
- No zuo no die.
- Let me see see.
- You can you up.
- Add oil.

Note:
Some items may be understood as memes or absorbed expressions in specific contexts.
Explain usage boundaries instead of declaring absolute wrongness.

## 2. Direct Translation Crashes

- Open the light -> Turn on the light.
- Close the light -> Turn off the light.
- Eat medicine -> Take medicine.
- Drink soup -> Have soup.
- My English is poor -> My English isn't very good.
- I very like it -> I really like it.
- I have no money -> I'm broke.

## 3. One Word Used Wrong

- boring / bored
- exciting / excited
- interesting / interested
- good / well
- hear / listen
- say / tell / speak / talk
- borrow / lend
- bring / take

## 4. Too-Simple Expression Upgrade

- very good -> That's great. / That's solid. / That's impressive.
- very beautiful -> gorgeous / stunning
- very tired -> exhausted
- very angry -> furious
- I think -> I'd say / I guess / The way I see it

## 5. Common Chinese Situations

- 随便 -> Up to you / I'm good with anything
- 你先来 -> Go ahead
- 慢慢来 -> Take your time
- 加油 -> You got this / Keep going
- 我请客 -> It's on me
- 我马上来 -> I'll be right there
