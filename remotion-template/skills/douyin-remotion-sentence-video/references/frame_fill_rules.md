# Frame Fill Rules

## Principle

A frame should feel occupied by intention, not by empty layout scaffolding.

Large boxes, borders, and panels are allowed only when they help focus.
They are not allowed as placeholders.

## Common Failure Pattern

- tall compare box
- text pushed to the top
- huge empty area below
- thin border doing all the visual work

This looks like PPT and fails immediately.

## Required Rules

- if a container is large, content must visually fill or structure that space
- text should usually sit around the optical center, not cling to the top edge
- support lines, icons, tags, motion, or contrast blocks should justify lower space if used
- comparison scenes should be balanced vertically and horizontally
- the viewer should notice the sentence first, not the frame decoration first

## Good Ending Compare Scene

- wrong and right are both clearly readable
- the two sides feel tense and intentional
- active emphasis moves between them
- there is no obvious dead zone
- the frame feels like a payoff board

## Bad Ending Compare Scene

- two empty rectangles
- tiny text in the upper third
- large blank padding below
- static hold with no evolving emphasis
