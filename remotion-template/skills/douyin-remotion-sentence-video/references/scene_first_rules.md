# Scene-First Rules

Sentence videos must have scene first, then explanation.

Each episode should choose one scene metaphor based on the sentence function.

## Misunderstanding Repair

Visual elements:

- phone chat bubbles
- typing...
- seen but no reply
- rainy window at night
- broken dialogue bubble
- one message deleted and retyped

## Emotional Contrast

Visual elements:

- pressure close-up on dark background
- text gradually gets heavier
- sentence speeds up
- A/B contrast tearing apart
- yellow warning tags

## Upgrade Replacement

Visual elements:

- low-level sentence gets crossed out
- advanced sentence slams in
- "别再说..." vs "换成..." contrast

## Universal Spoken English

Visual elements:

- chat conversation
- bullet-comment style repeat
- mini scene cards
- real daily-life objects

## Writing Upgrade

Visual elements:

- ordinary sentence gets pressed down
- advanced sentence opens up
- composition-paper undertone
- score-rise visual metaphor

## Rules

- Do not stop at saying "black/yellow high contrast background"; specify the scene.
- The scene does not need external images; CSS or Remotion-generated elements are enough.
- Scene elements should serve the sentence, not become decoration overload.
- Animal icons can only act as emotional reaction, not the main character.
- Every episode should include at least one concrete scene element such as chat bubbles, typing, rain, comparison lines, sentence strikeout, emotional tags, or broken bubble effects.
- Hand-drawn SVG or generated line art should enrich negative space, not become the main lesson card.
- Usage scenes should feel like a real moment or social setting, not like a textbook example grid.
- If a line is highly reusable, isolate it as the visual center and demote the scene label to support status.
- If the sentence topic is about register, formality, or context mismatch, make the scene contrast visible rather than explaining it only in text.
- Across a batch, rotate scene support and shell energy so episodes do not all feel born from the same one-screen mold.
- Leave the bottom platform-caption zone visually quiet and structurally safe; do not solve composition by pushing key text downward.
