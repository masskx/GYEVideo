# Contrast Teaching Rules

This format must use contrast to create hook and memory.

## Standard 30-45 Second Structure

0-3s:

- throw the wrong expression immediately

3-8s:

- explain the mismatch or wrong meaning

8-15s:

- show the natural fix

15-28s:

- place it in a real usage scene

28-40s:

- lock `wrong vs right`

## Visual Rhythm

- wrong expression should appear as big text
- wrong expression should be crossed, glitched, crushed, or marked wrong
- the fix should slam in as bold yellow text
- the middle should include `你以为` vs `实际听起来`
- the ending should show direct wrong-vs-right contrast
