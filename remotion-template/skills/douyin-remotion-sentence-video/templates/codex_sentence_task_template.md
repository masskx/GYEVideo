# Codex Task: Create A Douyin English Sentence Episode

Before writing code, output this diagnosis first:

`What is the biggest risk that this video becomes PPT-like, and how will I avoid it?`

Then work in this order:

1. Write the episode brief.
2. Write the first-three-second plan.
3. Write the scene metaphor.
4. Write the slot swap design.
5. Write `voiceScript`.
6. Write data files.
7. Generate the video deliverables.

Minimal user prompt template:

`Use the douyin-remotion-sentence-video skill. Automatically make 5 Douyin-friendly English sentence skeleton videos, bias toward emotional spoken English, and help me choose topics, write copy, and generate the videos.`
