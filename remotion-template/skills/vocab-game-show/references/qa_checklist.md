## Content
- [ ] 4–6 words, each with level, prefix gloss, literal, meaning, collocation; at most one 拓展.
- [ ] Each round's line says prefix → gloss → literal → word → meaning, matching the data exactly.
- [ ] Bonus question solved by one of today's words, one correct option, `sourceNote` set.

## Picture (contact sheet + `out/qa/<id>/`)
- [ ] Neighbouring scenes have different hues.
- [ ] The judgement burst does not cover the tiles or the meaning.
- [ ] Lightning grid: all words fit inside x 70–930, nothing clipped.
- [ ] The pig never covers an option or a tile; it stands on the floor line.
- [ ] Cover: show title, root tile, the pig, readable at thumbnail size.

## Sound
- [ ] Every tile drop / stamp / judgement has its sound; voice above the music.
- [ ] QA report: −14 LUFS ±0.5, peak ≤ −0.5 dBFS, no black frames.
